# 桌面版架构说明

## 运行结构

- `main.js`：Electron 主进程，负责窗口、内置浏览器视图、持久化会话、托盘、IPC 和状态同步。
- `preload.js`：通过 `contextBridge` 暴露受控桌面 API。
- `host.html`：加载桌面版后台逻辑并承接消息总线。
- `src/`：主界面、后台任务逻辑、样式和图标，是桌面程序的运行资源。
- `lib/core.js`：可独立验证的核心函数。
- `lib/debug-capture.js`：显式开启调试后保存现场。

## 构建边界

安装包只包含运行所需的主进程、预加载脚本、承载页、核心库、`src/` 资源和图标。回归测试、测试快照、基准源码、构建脚本和文档不进入最终安装包。

`lib/electron-lite.js` 是历史无头测试替身，仅供测试脚本使用，不参与正式 Electron 产品运行，也不会被打进安装包。

## 上传版基准

`tests/github-upload/` 只保留一份用户提供的原始插件代码，供回归验证对比。桌面版的实际运行代码位于 `src/`，二者不是重复安装资源。
